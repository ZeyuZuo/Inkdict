The first public release of Inkdict: an open dictionary format and an offline dictionary app that reads it.

## What is in it

- **Protocol v1, frozen.** Entry content, type registry, themes ([`spec/v1.md`](https://github.com/ZeyuZuo/Inkdict/blob/v0.1.0/spec/v1.md)) and the `.inkdict` pack format ([`spec/pack-v1.md`](https://github.com/ZeyuZuo/Inkdict/blob/v0.1.0/spec/pack-v1.md)), under CC BY 4.0.
- **The desktop app** for Linux, Windows and macOS: a word list that follows your typing (prefix matches, words containing the input, close spellings), entries drawn by each dictionary's own theme with part-of-speech tabs, pronunciation, cross-references, history, several dictionaries, light and dark.
- **The `inkdict` tool**: `inkdict pack` builds a dictionary from its source files; `words`, `show`, `render`, `themes` and `info` inspect one.
- **A sample dictionary**, `sample-en-zh.inkdict`, and a guide to [making your own](https://github.com/ZeyuZuo/Inkdict/blob/v0.1.0/docs/making-a-dictionary.md).

To start: install the app, open Settings (the gear icon at the bottom of the sidebar), choose 添加词典… (Add dictionary) and pick `sample-en-zh.inkdict`.

## Known limitations

- The app's interface is in Chinese only; an English interface is planned.
- The Windows and macOS builds are not code-signed, so the system warns on first start (on macOS: right-click the app, then Open). They are built and tested automatically but have not been tried by hand on those systems.
- No looking up selected text from other apps yet, and no Android app.
- Inkdict ships no dictionary content apart from the sample. Use dictionaries you have the right to use.
