# ZDict 词典协议 v0

状态：**已冻结**，2026-10-25。本文定义词条内容、类型表、主题三部分。冻结后发现的新情况只以补充规则的形式记在第 7 节，不改动已有类型和字段的含义。词典包（`.zdpack`）的格式见 `pack-v0.md`。

| 文件 | 作用 |
| --- | --- |
| `types.toml` | 类型表：有哪些类型、能包含什么、有哪些属性和功能角色 |
| `themes/default.toml` | 默认主题：每种类型怎么显示 |
| `pack-v0.md` | 词典包格式 |

v0 的类型集来自第一本接入的词典（牛津高阶英汉双解第 10 版）。各词典来源怎么转换到本协议，由各自的数据仓库记录（Oxford 见 OxDic 仓库 `docs/oxford-mapping.md`）。协议仓库不放词典正文。

## 1. 三层分工

| 层 | 只关心 | 不关心 |
| --- | --- | --- |
| 内容 | 原文、类型、少量属性（语言、ID、资源、跳转目标） | 字体、颜色、标点、编号格式 |
| 类型表 | 类型之间的嵌套关系、属性类型、功能角色 | 显示效果 |
| 主题 | 每种类型的显示效果 | 内容本身 |

同一份内容可以换主题；同一个主题可以用于不同词典。应用设置（如“隐藏中文”）也实现为叠加在主题之上的小主题，例如 `[style."*[lang=zh]"] display = "none"`。

## 2. 内容格式

一个词条是一棵节点树，以 JSON 存储。

```json
{"type": "example", "id": "…-2870", "children": [
  {"type": "example_text", "children": ["an ", {"type": "collocation", "text": "apple pie"}]},
  {"type": "example_text", "lang": "zh-Hans", "text": "苹果馅饼"}
]}
```

### 2.1 节点的键

| 键 | 说明 |
| --- | --- |
| `type` | 必填，类型表中的类型名 |
| `id` | 可选，源数据中的稳定 ID；同一词条内唯一 |
| `lang` | 可选，BCP 47 语言标签；不写则继承父节点，根节点 `entry` 必须写 |
| `attrs` | 可选，类型表声明过的属性 |
| `text` | 纯文本内容，等价于 `children: ["…"]` |
| `children` | 子节点数组，元素为节点或字符串；字符串只在类型表允许 `#text` 时出现 |

`text` 与 `children` 不能同时出现。空字符串、空数组、空对象不写入。

### 2.2 多语言

- **整段内容的不同语言版本，用同类型、不同 `lang` 的兄弟节点**：释义写两个 `definition`，例句写两个 `example_text`，说明框段落写两个 `paragraph`。
- **短文本附带的译文，用行内 `translation` 子节点**：标签 `law 律`、义项分组标题 `PRINTED WORK 印刷品`、用法限定 `used as a modal verb 用作情态动词`。

功能按 `lang` 工作：隐藏中文、只朗读英文等都不需要知道具体类型。

### 2.3 原文规范化

内容只保留原文，但去掉由主题负责生成的部分：

1. 块的首尾空白去掉；连续空白合并为一个空格。
2. 容器标点不保存：语法码的 `[` `]` 和分隔逗号、标签与变体的括号、`gloss` 的 `(= ` 和 `)`、引用引导语的 `->`、词族反义的 `≠` 和括号、`/` 分隔的 `alt`、`[OPP]` 一类方括号。
3. 编码解析为结构：`[Ox3000 key_L]` → `badge{scheme: ox3000}` 文本 `3000`（Ox5000 同理为 `ox5000`）；`[CEFR_A1_L]` → `badge{scheme: cefr}` `A1`；`[CET4]` → `badge{scheme: exam}` `CET4`；`[OPAL_W]` → `badge{scheme: opal}` `W`；`_L`/`_S`/`_M` 后缀是原网站的图标尺寸，丢弃。
4. 义项编号 `2.` → `sense.attrs.n = 2`。
5. 其余文字原样保留，包括音节点 `·`、重音符 `ˈ ˌ`、中文译文开头的 `*`（Oxford 数据中含义待查）。

## 3. 类型表格式

`types.toml` 中每个类型：

| 字段 | 说明 |
| --- | --- |
| `kind` | `block` 或 `inline`：主题未指定时的默认布局 |
| `children` | 允许的子类型；`#text` 表示字符串，`@inline`、`@head` 引用 `[groups]` 中的类型组 |
| `attrs` | 属性及其类型：`string`、`int`、`bool`、`res`（资源引用）、`ref`（ID 引用）、`enum(a\|b)`；末尾 `?` 表示可选 |
| `roles` | 与主题无关的功能：`index` 进检索索引，`audio` 可播放，`image` 图片，`link` 可跳转，`anchor` 可被跳转到 |
| `doc` | 说明 |

v0 共 81 种类型：

| 类别 | 类型 |
| --- | --- |
| 骨架 | `entry` `head` `pos_group` `sense_group` `sense_group_title` `sense` `definition` `example` `example_text` |
| 词头行 | `headword` `homograph` `badge` `pron_list` `pron` `region` `pron_form` `ipa` `pos` `grammar` `gram` `labels` `label` `conj` `variant` `variant_note` `variant_form` `inflections` `inflection` `infl_label` `infl_form` `infl_ending` `form_index` `use` `scope` `pattern` `translation` |
| 习语、短语动词、派生词 | `idiom_list` `idiom` `phrasal_verb_list` `phrasal_verb` `phrase` `placeholder` `derivative_list` `derivative` |
| 引用、说明、媒体 | `xref` `xref_label` `target` `target_phrase` `note` `image` `audio` `word_family` `family_word` `family_form` `family_opp` |
| 说明框 | `box` `box_ref` `box_title` `box_kind` `heading` `paragraph` `list` `list_item` `table` `row` `cell` |
| 行内标记 | `collocation` `gloss` `xword` `mention` `strong` `highlight` `self_ref` `related_form` `sup` `sub` `full_form` `alt` `weak` `br` `bullet` |

阅读器遇到类型表中没有的类型时，按 `inline` 显示其文本，不能报错。

## 4. 主题格式

`themes/*.toml`，四部分：

```toml
[meta]   format = "zdict-theme"; version = 0; name = "Default"
[fonts]  text = ["Source Serif 4", "Noto Serif", "serif"]     # 字体令牌 → 候选字体
[colors.light]  fg = "#1f2328"                                # 颜色令牌；light 与 dark 必须同名
[colors.dark]   fg = "#e6e7e9"
[style."sense > definition"]  display = "inline"              # 选择器 → 属性
```

### 4.1 选择器

| 写法 | 含义 |
| --- | --- |
| `definition` | 类型 |
| `*` | 任意类型 |
| `badge[scheme=cefr]` | 属性等于某值；布尔值写 `true`/`false` |
| `sense[n]` | 属性存在 |
| `definition[lang=zh]` | 语言按子标签前缀匹配：`zh` 匹配 `zh-Hans`；语言是继承后的值 |
| `idiom sense` | 后代 |
| `sense > head` | 直接子节点 |
| `sense::before` `sense::after` `idiom_list::title` | 只作用于 before/after/title 生成的文字 |
| `example::marker` `audio::icon` | 只作用于悬挂标记、图标 |

多条规则匹配同一节点时：属性条件多的优先，再比类型数，再按文件中的先后，后者覆盖前者。

### 4.2 属性

**文字属性**会被后代继承：

| 属性 | 取值 |
| --- | --- |
| `font` | 字体令牌 |
| `size` | 相对父节点的倍数，如 `0.8` |
| `weight` | `normal` `bold` |
| `style` | `normal` `italic` |
| `case` | `none` `upper` `lower` `small-caps` |
| `decoration` | `none` `strike` `underline` |
| `color` | 颜色令牌 |
| `baseline` | `normal` `super` `sub` |
| `line_height` | 行高倍数，如 `1.7` |

**盒属性**只作用于节点本身：

| 属性 | 取值与含义 |
| --- | --- |
| `display` | `block` `inline` `none`；不写时用类型表的 `kind` |
| `before` / `after` | 在内容前后插入的文字；可用 `{属性名}` 引用节点属性，引用的属性不存在时整段不显示 |
| `join` | 插在两个相邻的同类型兄弟节点之间；中间隔着字符串或其他类型时不插 |
| `title` | 块上方的标题文字 |
| `marker` | 块的悬挂标记，如 `◆`，画在 `indent` 留出的左侧空间里，正文整体对齐在标记右侧；可用 `{属性名}` |
| `icon` | 内容前的图标：`none` `speaker` `key` `arrow` `diamond`；`audio` 角色的节点用它作为播放按钮 |
| `hide_text` | `true` 时不显示自身文字，只显示图标和 before/after，如 Ox3000 只显示钥匙图标；有背景时渲染为正方形，`radius` 足够大即为圆形 |
| `space_before` / `space_after` | 块的上下间距（em） |
| `space_start` / `space_end` | 左右外间距（em），用于行内元素之间留空 |
| `indent` | 块的左缩进（em） |
| `background` `padding` `radius` | 背景色令牌、内边距、圆角（em）；有背景的行内元素不会被折行拆开 |
| `divider` | 底部分隔线的颜色令牌 |
| `collapse` | `none` `open` `closed`：可折叠；第一个子节点作为折叠后仍显示的摘要 |
| `max_width` | 最大宽度（em），用于图片 |

`::before`、`::after`、`::title`、`::marker`、`::icon` 只接受文字属性；`::title` 另可设 `space_after`，`::marker` 另可设 `icon`（用图标代替标记文字）。

### 4.3 渲染规则

1. 行首、行尾的空白不显示，与 CSS `white-space: normal` 相同。
2. `box_ref` 在原位置显示所引用的说明框，并使用 `box_ref` 上的 `collapse`；被引用过的 `box` 不在词条末尾重复显示。
3. 功能角色由应用处理：`audio` 角色显示播放控件，`link` 角色可点击，`index` 角色的文字进入检索索引（与 `display` 无关，`form_index` 隐藏但仍可检索）。

这些规则目前的参考实现是 OxDic 仓库的 `oxdic/preview.py`；Rust 核心和 Web 渲染器完成后，以本仓库的实现为准。

## 5. 资源引用

属性类型 `res` 的值为 `类别:键`：`wa` 单词音频、`xa` 例句音频、`img` 插图。键是源数据中的原始资源键，如 `wa:apple#_gb_5`。

词典包附带有序的资源源列表（见 `pack-v0.md` §6），例如：

```toml
[[source]]
kind = "wa"
template = "https://oxford-x-file.oss-cn-hangzhou.aliyuncs.com/audio/words/words_audio/{key:uri}.mp3"
```

`{key:uri}` 按 JavaScript `encodeURIComponent` 编码，`{key}` 为原样。同一类别有多个源时按顺序回退。更换媒体存储时只改资源源，内容文件不需要改动。

## 6. 链接目标

`link` 角色的节点（`target`、`xword`）按以下顺序决定跳到哪里：

1. 有 `entry` 和 `anchor`：打开词条 `entry`，滚动到 ID 为 `anchor` 的节点。
2. 只有 `entry`：打开词条 `entry`。如果 `anchor_type = wfg`，滚动到该词条的 `word_family` 节点。
3. 只有 `anchor`：在当前词条中找这个节点。
4. 以上都找不到：按节点的文字查词。

转换器应尽量让 `entry` 和 `anchor` 指向包内存在的节点；指不到的保留原值，由读取端按上面的顺序回退。

## 7. 冻结后的补充规则

以下规则只新增允许的结构或明确原有规则，不改变已有类型和字段的含义。

| 类型 | 新增允许的子类型 | 来源 |
| --- | --- | --- |
| `@inline` 组 | `label` `labels` `target` `pron_list` `pattern` `grammar` `use` `scope` `translation` | 正文中的标签、内嵌引用（Windsor → THAMES）、释义中的发音、说明框中的用法限定 |
| `entry` | `note` `xref` `image` | 词条级用法说明、引用、插图 |
| `pos_group` | `box_ref` `image` | 词性级说明框与插图 |
| `sense_group` | `xref` `box_ref` | 义项分组级引用与说明框 |
| `example` | `labels` `note` | 例句前的标签 `(computing 计)`；挂在单条例句上的用法说明 |
| `variant` | `grammar` `form_index` `inflections` `pos` | 变体组内的语法码、词形、词性 |
| `variant_form` | `infl_ending` `sub` `sup` `weak` | 变体词形中的词尾、上下标、弱读 |
| `inflection` / `inflections` | `labels` / `conj` | `-ll-, NAmE -l-`；`pl. Luo or Luos` |
| `idiom` `phrasal_verb` `derivative` | `xref` `note` | 习语、短语动词、派生词级引用与说明 |
| `idiom_list` `phrasal_verb_list` | `note` | 区块级说明 |
| `note` | `xref` | 说明中的“see also” |
| `list_item` | `grammar` `labels` `pos` `note` | 说明框列表项中的词条信息 |
| `heading` | `translation` | 说明框小标题的中文 |
| `cell` | `example` | 表格单元格中的例句 |
| `strong` `highlight` `mention` | `translation` | 表格中“英文词 + 中文”成对出现 |

### 7.2 主题叠加

§1 提到应用设置实现为叠加在主题之上的小主题，这里写明叠加规则：

1. 一次渲染使用一个**主题栈**：词典自带主题（包内 `files` 中的 `themes/*.toml`）在最底层，其上依次是应用选择的主题、用户设置生成的叠加层。
2. 上层的规则整体优先于下层，不比较选择器的具体程度；同一层内仍按 §4.1 的规则决定优先级。所以叠加层里的 `[style."*[lang=zh]"] display = "none"` 能覆盖底层任何更具体的规则。
3. `fonts`、`colors` 中的令牌按名字合并，上层同名令牌覆盖下层；叠加层可以只写 `[style]`，不必重复 `meta` 以外的部分。叠加层的 `meta.format` 同样为 `zdict-theme`。
4. 叠加层不能新增类型、修改内容或改变功能角色（`audio`、`link`、`index` 照常工作）；`display = "none"` 只影响显示，不影响检索。
