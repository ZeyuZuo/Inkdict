## 1. 职责划分

| 词典包决定 | 软件决定 |
|---|---|
| 词条内容、节点类型和嵌套 | 窗口布局、词表、历史、词典管理 |
| 词条怎么显示：标记、编号、字号、颜色、字体角色（主题） | 浅色还是深色；每个字体角色用哪款已安装字体；基础字号和缩放 |
| 语言声明、短释义 | 按包声明的 role 生成显示开关（发音、例句） |

软件只通过本协议定义的 **roles**（§3.2）和 **lang** 接触词条结构，不认任何词典自己的类型名。类型名属于每部词典。

## 2. 词条内容

一个词条是一棵 JSON 节点树：

| 键 | 说明 |
|---|---|
| `type` | 必填，类型表中的类型名 |
| `id` | 可选；同一词条内唯一。根节点的 `id` 必填，即词条的 key，在包内唯一，通常就是词头（同形词加后缀，如 `bank-2`）|
| `lang` | BCP 47 语言标签；根节点必填，其余不写则继承父节点 |
| `attrs` | 类型表声明过的属性 |
| `text` | 纯文本，等价于 `children: ["…"]`，与 `children` 不同时出现 |
| `children` | 子节点数组，元素为节点或字符串；字符串只在类型表允许 `#text` 时出现 |

空字符串、空数组、空对象不写。内容只存原文，括号、分隔符、编号格式等由主题生成。

外部深链：`<词条 key>#<节点 id>`。

## 3. 类型表（`types.toml`）

```toml
[meta]
format = "zdict-types"
version = 1

[groups]
inline = ["#text", "strong", "target"]

[types.pos_group]
kind = "block"                 # block | inline：主题未指定时的布局
children = ["head", "sense"]   # 允许的子类型；#text 为字符串，@名字 引用 [groups]
attrs = { n = "int?" }         # string | int | bool | res | ref | enum(a|b)；? 为可选
roles = ["anchor"]
index = "headword"             # 仅带 index 角色的类型：索引种类（§3.1）
doc = "说明"
```

类型名只用小写字母 `a`–`z` 和 `_`，即主题选择器能写出的名字（§4.1）。

读取端遇到类型表里没有的类型时，按 `inline` 显示其文字，不报错。

### 3.1 索引种类

带 `index` 角色的节点进入词形索引（`pack-v1.md` §3），`index` 字段取：

| 种类 | 含义 | 词表显示 |
|---|---|---|
| `headword` | 词头（含派生词等嵌套词头） | 词本身 |
| `variant` | 变体拼写 | 词本身 → 所属词头 |
| `inflection` | 屈折形式 | 词本身 → 所属词头 |
| `phrase` | 习语、短语、词语 | 短语本身 |
| `reading` | 读音拼写，用来查词（拼音、假名） | 词头 + 读音 |
| `hidden` | 只用于查到词条，自己不显示（如网站不显示的完整词形） | 显示为所属词头 |

### 3.2 roles

| role | 软件的行为 |
|---|---|
| `index` | 文字进入词形索引（与是否显示无关） |
| `anchor` | 这类节点带 `id` 时可被链接跳转、被词表定位（不是每个都要有 `id`，如只有一个词性的词条，它的词性分组可以没有） |
| `link` | 可点击，按 §6 跳转 |
| `audio` | 播放节点上 `res` 类型的属性（类型表里声明的第一个）；没有该属性时不显示播放按钮 |
| `image` | 显示节点上 `res` 类型的属性 |
| `homograph` | 同形词编号：文字是一个正整数，词表在词头后显示（`pack-v1.md` §2.3） |
| `pronunciation` | 受"发音"显示开关控制 |
| `example` | 受"例句"显示开关控制 |
| `optional` | 索引读法展开：可有可无（`the lower middle classes` → 有无 `the` 两种） |
| `choice` | 索引读法展开：相邻的同类节点选其一（`pull/drag` → 两种） |

软件里的开关只在包声明了对应 role 时出现。

## 4. 主题（`themes/<name>.toml`）

```toml
[meta]
format = "zdict-theme"
version = 1
name = "默认"

[fonts.text]                              # 字体令牌，按语言给候选字体
default = ["Source Serif 4", "serif"]
"zh-Hans" = ["Noto Serif CJK SC", "serif"]

[colors.light]  fg = "#1b1c1f"            # 颜色令牌；light 与 dark 必须同名
[colors.dark]   fg = "#e5e5e7"

[style."sense > definition"]  display = "inline"
```

字体令牌对每个节点按其 `lang` 选：先找完全相同的标签，再找主标签（`zh-Hans` → `zh`），最后用 `default`。

### 4.1 选择器

| 写法 | 含义 |
|---|---|
| `definition` / `*` | 类型 / 任意类型 |
| `badge[scheme=core]` / `sense[n]` | 属性等于某值 / 属性存在；布尔值写 `true`、`false` |
| `definition[lang=zh]` | 语言按子标签前缀匹配，使用继承后的值 |
| `idiom sense` / `sense > head` | 后代 / 直接子节点 |
| `::before` `::after` `::title` `::marker` `::icon` | 只作用于生成的文字、标记、图标 |

多条规则匹配同一节点时：属性条件多的优先，再比类型数，再按文件中的先后，后者优先。

### 4.2 属性

文字属性（继承）：`font`（令牌）、`size`（相对父节点倍数）、`weight`（normal/bold）、`style`（normal/italic）、`case`（none/upper/lower/small-caps）、`decoration`（none/strike/underline）、`color`（令牌）、`baseline`（normal/super/sub）、`line_height`。

盒属性（不继承）：

| 属性 | 含义 |
|---|---|
| `display` | `block` `inline` `none`；不写时用类型表的 `kind` |
| `before` / `after` | 前后插入的文字；`{属性名}` 引用节点属性，属性不存在时整段不显示 |
| `join` | 插在相邻的同类型兄弟节点之间 |
| `title` | 块上方的标题 |
| `marker` | 悬挂标记，画在 `indent` 留出的行首空间里；可用 `{属性名}` |
| `icon` | `none` `speaker` `key` `arrow` `diamond`；`audio` 角色用它作播放按钮 |
| `hide_text` | 只显示图标和 before/after |
| `space_before` `space_after` `space_start` `space_end` `indent` | 间距（em）；start/end/indent 按书写方向的行首、行尾 |
| `background` `padding` `radius` | 背景色令牌、内边距、圆角 |
| `divider` | 底部分隔线颜色令牌 |
| `collapse` | `none` `open` `closed`；第一个子节点作为折叠后的摘要 |
| `max_width` | 最大宽度（em），用于图片 |
| `tabs` | `true`：相邻的这类兄弟节点画成标签页，见 §4.4 |
| `tab_label` | 选择器，在节点内部找标签文字，见 §4.4 |
| `tab_accent` | 选中标签的指示线颜色令牌；不写时用标签文字的颜色 |

`::` 伪元素只接受文字属性；`::title` 另可设 `space_after`，`::marker` 另可设 `icon`。

### 4.3 渲染规则

1. 行首、行尾空白不显示（同 CSS `white-space: normal`）。
2. 书写方向由节点 `lang` 的文字决定（阿拉伯文、希伯来文等从右到左）。
3. 主题栈：包主题在下，用户主题（可选）在上；上层规则整体优先于下层，令牌按名字合并。

### 4.4 标签页

是否用标签页、标签写什么，都由主题决定，软件不另作判断。

```toml
[style.pos_group]
tabs = true
tab_label = "head > pos"
tab_accent = "accent"
```

1. 同一父节点下相邻的、`tabs = true` 的兄弟节点组成一组标签页，标签栏画在第一个节点的位置；一次只显示其中一个节点。一组只有一个节点时照常显示，不画标签栏。
2. 标签文字是节点内第一个匹配 `tab_label` 的后代的文字，使用该后代的文字属性；这个后代在标签页内不再显示。找不到时标签写序号（1、2、3…）。
3. 默认显示第一个；要打开的位置（链接锚点、词表定位的锚点）在某个标签页内时，显示那一个。
4. 用户主题可以写 `tabs = false` 关掉标签页，各节点按普通的块依次显示。

## 5. 语言

包在 manifest 中声明 `source`（词头和原文的语言）与 `targets`（译文语言，单语词典为空），软件只用它们在词典管理里显示词典的语言。

节点的 `lang` 决定字体（§4）和书写方向（§4.3）。软件没有语言开关：词条里的所有语言都照常显示。要隐藏某种语言，可以用用户主题，例如 `[style."definition[lang=zh]"] display = "none"`。

发音、例句开关只影响显示，不影响索引。

## 6. 链接

`link` 角色的节点（`attrs.entry`、`attrs.anchor`）按顺序决定目标，每条只在目标存在时成立：

1. `entry` 在包内：打开它；`anchor` 是该词条内的节点 id 时滚动到那里，否则停在开头。
2. `anchor` 是当前词条内的节点 id：滚动到那里。
3. 都不成立：用节点的全部文字查词。

## 7. 资源引用

`res` 属性的值为 `类别:键`（如 `audio:harbour-gb`）。读取端先查包内 `resources` 表，没有再按 `resource_sources` 的模板依次在线取（`pack-v1.md` §4）。
